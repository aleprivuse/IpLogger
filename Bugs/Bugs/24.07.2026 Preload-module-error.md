# Electron Preload Script Not Loading

## Problem

The Electron preload script was not loading correctly.

Because the preload failed, the renderer process could not access the API exposed through `contextBridge`.

---

## Symptoms

The renderer returned:

```text
TypeError: Cannot read properties of undefined (reading 'getLogs')
```

Example:

```javascript
window.sshLogs.getLogs()
```

failed because:

```javascript
window.sshLogs === undefined
```

The `contextBridge` API was never created because the preload script failed.

---

## Initial Error

Electron showed:

```text
Unable to load preload script:
/home/maintest/Iplogger/preload.js
```

The first assumption was that the preload path was incorrect.

---

# Debugging Process

## Step 1 - Check preload path

Checked:

- Preload file location ✅
- `path.join()` configuration ✅
- Absolute path ✅
- Folder structure ✅

The path was correct.

Example:

```javascript
webPreferences: {
    preload: "/home/maintest/Iplogger/preload.js"
}
```

---

## Step 2 - Test preload execution

The preload file was simplified:

```javascript
console.log("PRELOAD WORKING");
```

The preload still failed.

### Conclusion

The issue was not the preload logic itself.

The preload file was found, but Electron failed while trying to execute it.

---

# Real Cause

After checking the full Electron console error:

```text
SyntaxError: Cannot use import statement outside a module
```

The preload script contained:

```javascript
import { contextBridge, ipcRenderer } from "electron";
```

However, the preload script was not configured to run as an ES Module in this Electron setup.

The main process and preload script do not always share the same module behavior.

The project used:

```json
"type": "module"
```

which allowed ES Module syntax in the main process, but the preload script required a different module format.

---

# Solution

Changed preload from ES Module syntax:

```javascript
import { contextBridge, ipcRenderer } from "electron";
```

to CommonJS syntax:

```javascript
const { contextBridge, ipcRenderer } = require("electron");

contextBridge.exposeInMainWorld("sshLogs", {
    getLogs: () => ipcRenderer.invoke("Get-logs")
});
```

---

# Result

The preload script loaded successfully.

The renderer could now access:

```javascript
window.sshLogs
```

and call:

```javascript
window.sshLogs.getLogs()
```

IPC communication started working.

---

# Lessons Learned

## Error messages can be misleading

`Unable to load preload script` does not always mean the path is wrong.

Possible causes:

- Wrong file path
- Syntax error
- Import error
- Runtime crash
- Module system mismatch

---

## Always read the full error

The first error:

```text
Unable to load preload script
```

was not the real problem.

The actual error:

```text
Cannot use import statement outside a module
```

explained the cause.

---

# Debugging Strategy

When debugging Electron:

1. Test the smallest possible version.
2. Remove unnecessary code.
3. Check which process is failing.
4. Read the complete error message.
5. Fix one layer at a time.
